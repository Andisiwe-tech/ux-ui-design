# Pine City Zoo App

Welcome to the Pine City Zoo App! This project is a responsive, multi-page website for a fictional zoo, built with HTML and CSS.

## Features

- **Interactive Map:** Explore the zoo layout and navigate to different areas.
- **Animal Information:** Learn about various animals with dedicated info pages.
- **Places to Visit:** Discover attractions, restaurants, and picnic spots within the zoo.
- **Weather Updates:** Check the latest weather forecast for your visit.
- **Feedback Form:** Share your thoughts and suggestions with the zoo team.

## Project Structure

```
Pine City Zoo/
  ├── index.html
  ├── animals.html
  ├── places.html
  ├── weather.html
  ├── feedback.html
  ├── style.css
  ├── images/
  └── [other animal and place pages]
```

## How to Use

1. **Clone or Download** this repository.
2. Open `index.html` or any page in your browser.
3. Navigate using the top and bottom tabs to explore the zoo.
